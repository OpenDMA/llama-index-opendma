# LlamaIndex Tools for OpenDMA

LlamaIndex tools for [OpenDMA](https://opendma.org/).

OpenDMA is a vendor-neutral abstraction layer for enterprise content management
systems. It provides a common API for repositories such as Alfresco, CMOD,
Documentum, FileNet P8, OnBase, SharePoint, and other ECM or document management
platforms.

This package provides a convenient ToolSpec allowing agentic applications
to browse through complex repository layouts to retrieve information.

## Installation

```bash
pip install llama-index-tools-opendma
```
